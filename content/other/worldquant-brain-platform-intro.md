### 1. 引言


我最开始认真看 WorldQuant BRAIN，并不是因为我已经准备好做量化，而是因为我发现它和普通的学习路径不太一样：它不是先给你一套完整答案，而是直接把你放到一个不断验证、不断修正的研究环境里。


这也是为什么我会先写这篇平台介绍。后面的内容无论是复盘、踩坑，还是方法上的变化，都得先建立在一个前提上：你至少要知道 BRAIN 到底是什么，它为什么会让人越做越像在做研究。


**WorldQuant BRAIN** 是一个基于网页的量化金融研究与回测平台，由全球知名量化资产管理公司 **WorldQuant** 推出。截至 2026 年，该平台已拥有超过 **55 万注册用户** 和 **1.6 万余名签约研究顾问**，覆盖全球 17 个国家和地区。


BRAIN 的核心使命可以用一句话概括：**让全球人才都能参与量化金融信号的研发，并通过贡献高质量的研究成果获得回报。**


平台提供了一套完整的基础设施：从海量清洗好的金融数据、到专门设计的表达式语言、再到极速的历史回测引擎，用户只需要专注于一个核心任务——**发现能够预测金融资产价格变动的数学模型（即 Alpha）**。


这种模式被外界称为 **“Alpha Factory”（阿尔法工厂）**：不是依赖少数天才策略，而是通过众包方式，让成千上万个微弱但互不相关的预测信号汇聚成一个稳健的"超级组合"。

### 2. WorldQuant：平台背后的公司


要理解 BRAIN，首先要了解它的母公司 **WorldQuant**。


**WorldQuant** 成立于 **2007 年**，总部位于美国康涅狄格州格林威治，由 **Igor Tulchinsky** 创立。Igor 在创立 WorldQuant 之前，曾在 Millennium Management 担任统计套利投资组合经理长达 12 年。他拥有德克萨斯大学计算机科学硕士学位（仅用 9 个月完成）和沃顿商学院 MBA 学位。


在他的带领下，WorldQuant 已发展成为一家拥有 **1,100 余名员工**、**28 个全球办公室** 的量化资产管理公司，管理资产规模约 **270 亿美元**。公司不仅在传统量化投资领域深耕，还创办了 WorldQuant University（提供免费的金融工程硕士项目）、WorldQuant Ventures（科技投资）和 WorldQuant Predictive（AI 预测平台）。


Igor Tulchinsky 的一个核心信念是：


> **“Talent is distributed equally around the world, opportunity is not.”** （人才在全球均匀分布，但机会并非如此。）


刚看到这句话时我其实半信半疑，觉得更像是公关话术。直到自己真的靠一个朴素的表达式拿到了第一次正反馈，才相信这扇门确实是对普通学生敞开的。


BRAIN 平台正是这一理念的产物——它试图打破地理和机构的壁垒，让任何具备分析能力和好奇心的人都能参与顶级量化研究。我个人比较喜欢这句话，因为它让我第一次觉得，量化研究并不一定只能发生在大型金融机构，普通学生也可以通过公开的平台参与其中。

### 3. 核心概念：什么是 Alpha


在 BRAIN 的语境中，**Alpha** 有极其明确的定义：


> **Alpha 是一个旨在预测各种金融工具未来价格走势的数学模型。**


它不是一段复杂的 Python 交易系统，不需要包含止损、仓位管理或资金曲线控制。Alpha 的核心输出是一个**权重向量**——对于股票池中的每一只股票，它给出一个数值，表示"今天应该做多还是做空、以及多少"。


---


#### Alpha 的本质：一个表达式


Alpha 在 BRAIN 上通常表现为一个**数学表达式**。例如：


```
rank(-returns)

```


这个表达式的假设是：“今天收益率相对较低的股票，明天可能表现更好”。平台会针对这个表达式在历史数据上进行回测，验证这个假设是否成立。


另一个例子：


```
operating_income / cap

```


这是最简单的基本面 Alpha 之一——用营业利润除以市值，寻找"被相对低估"的股票。


我刚开始学习的时候，一直把 Alpha 理解成“交易策略”，后来真正开始回测以后才发现，平台更关心的是信号本身，而不是完整的交易系统。


#### 一个"好" Alpha 的标准


平台对 Alpha 有一套严格的量化评价指标：


 | 
 | 指标 |  | 含义 |  | 提交门槛（Delay-1） |  | 
 | **Sharpe（夏普比率）** |  | 风险调整后的收益，越高越好 |  | > 1.25 | 
 | **Fitness（健康度）** |  | 综合 Sharpe、收益和换手率的指标 |  | > 1.0 | 
 | **Turnover（换手率）** |  | 每日交易活跃程度，过高会增加成本 |  | 1% ~ 70% | 
 | **Returns（年化收益率）** |  | 平均年化盈亏百分比 |  | 越高越好 | 
 | **Drawdown（最大回撤）** |  | 资金曲线的最大下跌幅度 |  | < 10% 为佳 | 
 | **Self-Correlation（自相关性）** |  | 与已提交 Alpha 的相似度 |  | < 0.7 |

表里的门槛看着简单，但我前两周几乎全卡在 Fitness > 1.0 这一行上。后来复盘才发现，Sharpe 其实够了，是 Turnover 没控制好导致 Fitness 被拖垮。


值得注意的是，普通用户阶段提交的因子通常只看 **5 年 IS（样本内）** 测试结果，还不会开启 OS 测试；**OS（样本外）** 测试一般会在顾问阶段才开启，用来进一步检验因子的稳健性，防止过拟合。

### 4. 回测引擎：平台如何运作


BRAIN 的回测引擎是整个平台的技术核心。它负责将用户输入的 Alpha 表达式转化为每日的投资组合，并计算历史表现。


#### 回测的七个步骤


以一个简化的例子说明（假设回测池中有 8 只股票，表达式为 `rank(-returns)`，延迟 1，衰减 0，子行业中性化）：


**步骤 1：评估表达式，生成 Alpha 向量**


- 对于每一天（由于延迟 1，使用 T-1 日数据），计算每只股票表达式的结果。
- `rank(-returns)` 会将收益率从低到高排序，输出 0 到 1 之间的均匀分布值。
- 收益率最低的股票获得最高值，表示"做多"信号最强。


**步骤 2：中性化（Neutralization）**


- 从每个值中减去该组的平均值，使所有值的总和为 0。
- 这确保了组合是**市场中性**的——整体不押注市场涨跌。
- 可以按市场、行业、子行业进行分组中性化。


> 新手易错点：很多人在这一步忘了选分组维度，默认全市场中性化会导致行业暴露失控，Sub-universe 测试直接挂掉。建议至少做到子行业级别中性化。


**步骤 3：缩放/标准化（Scaling）**


- 将向量值的绝对值之和标准化为 1，得到每只股票的**权重**。
- 正权重表示做多，负权重表示做空。


**步骤 4：分配资金**


- 假设账面规模（Booksize）为 2000 万美元。
- 每只股票的投资金额 = 权重 × 2000 万。
- 例如，某股票权重为 -0.22，则做空 440 万美元；权重为 0.03，则做多 60 万美元。


**步骤 5：计算每日盈亏（PnL）**


- 根据当天股票的实际收益率，计算每只股票的盈亏。
- 将所有股票的盈亏相加，得到当天的组合 PnL。


**步骤 6：重复步骤 1-5**


- 对回测期内的每一天重复上述操作，生成完整的日收益序列。


**步骤 7：绘制累积 PnL 曲线**


- 将每日 PnL 累加，得到 Alpha 的累积盈亏曲线。
- 默认展示 5 年样本内期（IS）+ 2 年样本外期（OS）。


#### 衰减（Decay）的作用


如果设置了衰减（如 Decay = 3），最终权重不是当天的权重，而是当天与前几天权重的加权平均：


```
最终权重 = (当天权重 × 3 + 前一天权重 × 2 + 前两天权重 × 1) / 6

```


衰减的作用是**减少换手率、平滑信号**，防止 Alpha 对短期噪音过度反应。


我自己前期几乎一直使用 `Decay = 0`，后来慢慢才意识到，适当增加衰减有时候反而能让结果更稳定。

### 5. 表达式语言与数据生态


#### Fast Expression Language


BRAIN 使用一种专有的**快速表达式语言（Fast Expression Language）**，它本质上是一种伪代码，介于自然语言和编程语言之间。它的设计目标是让用户专注于"投资逻辑"，而不是陷入技术实现细节。


表达式的基本构成：


- **数据字段（Datasets）**：如 `close`（收盘价）、`volume`（成交量）、`returns`（收益率）、`operating_income`（营业利润）等
- **运算符（Operators）**：如 `rank`（排序）、`ts_mean`（时间序列均值）、`group_neutralize`（分组中性化）等
- **常数和标点**：数字、括号、分号、注释符号等


例如：


```
rank(ts_mean(returns, 20))  // 过去20天平均收益率的横截面排序

```


#### 数据规模


- **数据字段**：平台提供超过 **15 万+ 数据字段**（普通用户可用约 12 万，顾问解锁后可达 40 万+）
- **覆盖区域**：美国（USA）、中国（CHN）、亚太（ASI）、欧洲中东非洲（EMEA）、全球（GLB）等
- **数据类型**：价格成交量（Price-Volume）、基本面（Fundamental）、分析师数据（Analyst）、期权隐含波动率（Option IV）、新闻情绪（Sentiment）、另类数据等
- **股票池**：TOP500、TOP1000、TOP2000、TOP3000 等按流动性排序的证券池


#### 常用运算符分类


 | 
 | 类别 |  | 示例运算符 |  | 功能 |  | 
 | **算术** |  | `+`, `-`, `*`, `/`, `abs`, `log`, `power` |  | 基本数学运算 | 
 | **横截面** |  | `rank`, `zscore`, `normalize` |  | 在同一天内对所有股票排序或标准化 | 
 | **时间序列** |  | `ts_mean`, `ts_std_dev`, `ts_sum`, `ts_delta`, `ts_corr` |  | 对单只股票的历史数据做统计 | 
 | **分组** |  | `group_neutralize`, `group_rank`, `group_mean` |  | 按行业、市值等分组操作 | 
 | **回归** |  | `regression_neut`, `ts_regression` |  | 去除与其他因子的线性相关性 | 
 | **条件** |  | `if_else`, `greater`, `less` |  | 条件判断和筛选 | 
 | **特殊** |  | `trade_when`, `pasteurize`, `decay` |  | 交易触发、数据过滤、平滑处理 |

### 7. 成长路径：从新手到 Research Consultant


BRAIN 平台设计了一套清晰的用户成长体系：


#### 阶段 1：新用户（试用权限）


- 注册后获得基础权限
- 导航栏为蓝色
- 可用数据字段、回测区域和功能受限
- 并发模拟次数有限


#### 阶段 2：Gold 用户


- 通过提交 Alpha 累积 Challenge Score，达到 **10,000 分** 后升级为 Gold Level
- 积分每日上限 **2000 分**（T+1 更新，北京时间下午 2-3 点）
- 达到 Gold 后，有机会收到 **Consultant 邀请**


> 重要提醒：积分只反映活跃度，不代表研究能力。我在第一篇里说过“研究成功 ≠ 提交成功”，真正决定能否通过顾问审核的，是你 Alpha 的质量和相关性，而不是单纯的数量。


#### 阶段 3：Research Consultant（研究顾问）


- 填写顾问申请表（注意阅读填写指南，避免被退回）
- 签署顾问合同
- 获得 **顾问权限**（导航栏变为绿色），解锁：


- 更多数据字段（欧洲、亚洲等 40 万+ 字段）
- 更长回测周期
- 数据可视化工具
- 并行回测
- Python API 调用
- SuperAlpha 创建
- 顾问专属论坛和培训

- 进入 **3 个月试用期**，之后根据表现提升 “Value Factor”（级别因子）
- 顾问阶段的提交会开启 OS 测试，奖金通常也会结合 OS 表现以及其他指标综合评估
- 报酬基于 Alpha 质量和活跃程度，从几百元到数万元不等
- 最高级别（Grandmaster）季度奖金可达 **8,000 美元** 或更多
- 有机会获得实习和全职职位推荐


我目前也正在等待顾问审核，因此这一部分更多参考官方公开资料整理。


#### 重要提醒


- 在金融机构或金融科技公司任职的人员，可能因利益冲突无法成为顾问
- 顾问身份申请有 **20 天** 完成时限，过期会失效
- 审核顺序按提交数量和回测数量排序，更多提交 = 更短等待时间

### 8. 国际量化锦标赛（IQC）


**International Quant Championship（IQC）** 是 WorldQuant 每年举办的全球性量化竞赛，2026 年的赛事吸引了来自 100 多个国家的团队参与。


#### 赛制


**第一阶段：预选赛（Qualifier Round）**


- 时间：3 月 17 日 - 5 月 18 日
- 1-4 人组队，所有队员来自同一所大学
- 在 BRAIN 平台上创建和提交 Alpha，累积积分
- 平台会展示各大学的综合排名榜


**第二阶段：国家/区域赛（National/Regional Round）**


- 时间：5 月 26 日 - 7 月中旬
- 各区域排名前列的团队晋级
- 奖金：第一名 3,000 美元，第二名 2,000 美元，第三名 1,000 美元


**第三阶段：全球总决赛（Global Finals）**


- 时间：2026 年 9 月（新加坡）
- 全球各区域的优胜团队同台竞技
- 奖金：第一名 20,000 美元，第二名 12,000 美元，第三名 8,000 美元


#### 参赛价值


- 总奖金池 **10 万美元**
- 优秀选手有机会获得 BRAIN 顾问资格、实习或全职职位
- 与全球量化爱好者同台竞技
- 免费参赛，无门槛限制

### 9. 平台的独特价值


综合以上介绍，BRAIN 平台的核心价值可以归纳为以下几点：


#### 零基础设施成本


传统量化研究需要自建数据 pipeline、回测框架、计算集群。BRAIN 将这些全部云化，用户只需一个浏览器和灵感即可开始。


#### 工业级反过拟合机制


平台通过严格的 **OS 盲测**、**自相关性审查**、**子宇宙稳健性测试** 等多层筛选，确保入选 Alpha 不是数据挖掘的幸存者。这让研究者养成"可重复、可验证"的研究习惯。


#### 信号研究与组合管理的解耦


用户不需要做仓位管理、止损、资金曲线控制——这些由 WorldQuant 内部的投资组合经理负责。用户的唯一任务是生产**高质量、低相关性的预测信号**。


#### 真正的" merit-based "机会


无论你的学历、背景、地理位置如何，只要你能持续产出稳健的 Alpha，就能获得报酬和认可。这是量化金融领域少有的"能力至上"通道。


#### 学习与研究的一体化


平台本身就是一所"实战学校"。从 Learn 模块的基础知识，到回测中的试错反馈，再到社区的进阶讨论，整个学习曲线被内嵌在研究流程中。

### 10. 结语：适合谁，不适合谁


#### 适合谁？


- **对量化金融感兴趣的学生和工程师**：想验证自己对市场的数学直觉
- **计算机/数学/物理/AI 背景的人**：擅长处理数据、构建模型、寻找模式
- **希望建立量化研究习惯的初学者**：平台强迫你养成"回测-评估-迭代"的严谨流程
- **寻找远程兼职机会的人**：Consultant 项目提供灵活的研究报酬
- **计划申请量化实习或全职职位的人**：IQC 和顾问经历是简历上的有力加分项


#### 不适合谁？


- **寻求快速致富的人**：Alpha 研究需要长期积累，短期报酬不稳定
- **只想复制模板不思考的人**：平台的相关性审查会淘汰雷同思路
- **期望直接控制实盘交易的人**：你只是信号生产者，不管理投资组合
- **没有耐心处理大量失败的人**：90% 的 Alpha 尝试都会失败，这是常态
