本站由 Hugo 静态站点生成器构建，在 PaperMod 主题之上自定制了「inkline 纸墨编辑风」设计系统：

- 设计令牌（token）驱动的蓝色调亮色主题 + 编辑器暗色主题，全站统一风格
- 零 CDN 依赖的内联 SVG 图标、入场动画、响应式布局
- GitHub Actions + GitHub Pages 自动构建部署
